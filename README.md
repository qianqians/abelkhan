## ablekhan
abelkhan是一个轻量级的游戏服务器框架，基于c#开发，使用mongodb提供数据存储，支持c#和typescript前端，目标是提供一个稳定、高效、可扩展的服务器框架。  

## 架构
* 基于consul实现服务发现
* 基于Apache Fory实现序列化/反序列化
* 
* dbproxy 数据库代理
* gate 网关服务器
* hub 微服务节点
